# Getting Started with Foundation

Foundation is a powerful front-end framework that helps you build responsive websites quickly.

## Installation

You can install Foundation via npm, Composer, or download it directly. The npm installation gives you the most flexibility and control over your project setup.

## Your First Page

Once installed, open the index.html file in your browser. You'll see a basic Foundation page with a grid system already in place. Start customizing it to see how easy Foundation makes responsive design!
