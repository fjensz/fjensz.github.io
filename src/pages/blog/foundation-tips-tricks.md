# Foundation Tips and Tricks

Advanced tips and tricks to get the most out of Foundation for Sites.

## Customizing the Build

Foundation allows you to customize which components to include in your build. This keeps your CSS file size down by only including what you need. Visit the Foundation download page to create a custom build.

## Using Interchange

Foundation's Interchange component lets you conditionally load content based on screen size. This is perfect for loading different images or layouts for mobile versus desktop users.
